# References

이번 단계(Phase 2)에서는 외부 이미지와 웹 자료를 내려받거나 조회하지 않았다. 그래서 이 폴더에 이미지가 없다.

`art-direction/SPEC.md` §2의 레퍼런스 메모는 일반적으로 알려진 작품 특징에 대한 기억이며, 검증되지 않았다.

외부 자료를 추가할 때는 파일마다 다음을 기록한다.

- 출처 URL
- 저작권자
- 라이선스 또는 사용 권한
- 참고한 부분(구도, 팔레트, 조명 등)

출처나 권한이 불명확한 자료는 최종 에셋 제작에 쓰지 않는다.

마스코트 정체성(Codex: 파란 구름 머리 로봇과 `>_` 얼굴, Claude: 주황 크리터)은 사용자가 이전 대화에서 제공한 참고 이미지와 기존 TUI 스프라이트(`src/orca_orchestrator/console/sprites.py`)를 근거로 했다.
