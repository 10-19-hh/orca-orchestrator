# Character Spec — Claude 펫과 Codex 펫

펫 하나는 확인된 세션 하나다(`topology@1` `agent_sessions[]`). 같은 Provider의 세션이 셋이면 펫도 셋이다. 펫이 있다는 것은 세션이 있다는 뜻일 뿐이며, 무엇을 하고 있는지는 `presentation.intent`가 정한다.

## 1. 정체성

### Claude

- 작고 각진 주황 몸통. 가로가 세로보다 길다(1× 시안 몸통 12×7 px).
- 몸통 가운데 높이 양옆에 짧은 네모 돌기(팔)
- 짧은 다리 4개를 두 쌍으로 나누고 가운데를 조금 더 띄운다.
- 눈은 네모난 검은 점 두 개뿐이다. 입·코·볼 표현은 없다.
- 하지 않는 것:
  - 둥근 문어형, 촉수, 긴 다리
  - 스티커 외곽선(흰 테두리)
  - 과한 디테일
  - 이전 시안의 둥근 모서리 몸통(`../character-studies`의 32px 시안은 비교용)
- 색:
  - 몸통 `#D7774E`, 밝은 면 `#E8946A`, 그늘 `#B45E3B`
  - 테두리: 몸통보다 어두운 같은 색조 `#6E3220`
  - 눈 `#2A1712`

### Codex

- 파란 구름 머리, 어두운 터미널 화면 얼굴에 `>_`
- 작은 밝은 로봇 몸, 짧은 팔과 다리
- 기존 정체성(`../character-studies`)을 유지한다.
- 색:
  - 구름 `#A9D2F7`/그늘 `#86B0DC`, 테두리 `#35548F`
  - 화면 `#1E2A44`, 글리프 `#8FE3F0`
  - 몸 `#DFE7F1`, 관절 `#8FA3C4`

### 공통

- 두 펫의 **픽셀 밀도를 같게** 한다. 1× 화면에서 1 px = 1 px이고, 가구와 같은 격자를 쓴다.
- 실루엣 크기를 억지로 맞추지 않는다. Claude는 낮고 넓고 Codex는 좁고 높다. 화면에서 차지하는 면적이 비슷하면 된다(1× 시안 Claude 16×11, Codex 13×15).
- 제작 캔버스는 **32×32**, 기준점(pivot)은 `(16, 31)`로 두 발 사이 바닥이다. 레이아웃 시안의 1× 스프라이트는 비율 확인용이며, 제작 때 32×32 캔버스에서 같은 밀도로 다시 그린다.
- 조명은 왼쪽 위가 밝고 오른쪽 아래가 어둡다. 방의 창문 빛 방향과 같다.
- Provider가 `unknown`·`other`인 세션은 별도의 중립 펫을 쓴다(회색 상자형, 제작 목록에 포함). 제목을 보고 Claude나 Codex로 추정하지 않는다.

## 2. 상태 표현 (소품과 말풍선)

감정과 상태는 얼굴을 바꾸기보다 **소품과 말풍선**으로 표현한다. 색만으로 구분하지 않고 글리프를 함께 쓴다.

| 상태 | 표현 | 근거 (`intent`) |
| --- | --- | --- |
| 작업 | 자기 책상에 앉음, 모니터 켜짐 | `work` |
| 사용자 확인 필요 | 자리에서 `!` 말풍선 (주의색) | `attention` |
| Worker 정리 중 | 자리에서 `...` 말풍선 | `finishing` (연결 근거가 있을 때만) |
| 관측 불가 | 흐리게(회색 55%) + `?` 말풍선, 자리 유지 | `unobservable` |
| 작업 끝남 | 일어서서 `+` 말풍선, 짧은 기쁨 | `work_done` |
| 대기 | 커피 잔, 소파, 낮잠 `Z`, 산책, 비질 | `ambient` (연출) |
| 오류 | `X` 말풍선 | 예약. topology@1에는 오류 상태가 없음 |
| 퇴장 | 문으로 걸어가 문턱에서 사라짐 | `exit` |

`mockups/character-poses`에 13가지 포즈가 있다.

## 3. 방향과 프레임 (제작 요구)

- 방향 4개: SE·SW(얼굴이 보임), NE·NW(등이 보임). SE↔SW와 NE↔NW는 좌우 반전을 허용한다. 얼굴 글리프(`>_`)처럼 비대칭인 부분은 반전 뒤 다시 그린다.
- 애니메이션 목록·프레임 수·시간·반복 정책은 `asset-specification/asset-manifest.json`의 `characters[].animations`에 있다. 23종이며 각각 재생 조건이 붙어 있다.
- Typing·Thinking·Building은 목록에 있지만, 재생 조건은 "향후 관측 근거가 생길 때"다. topology@1에서는 재생하지 않는다.

## 4. 같은 Provider의 여러 펫

- 펫은 `session_id`로 구분한다. 같은 Provider 펫을 구분하는 표지는 둘이다.
  - 책상 명패의 슬롯 번호(A1…)
  - Inspector에서 보이는 세션 ID 끝 4자리
- 색을 바꿔 구분하지 않는다. Provider 정체성 색을 지키기 위해서다. 작은 액세서리 변주(목도리, 배지 등 4종)는 Phase 2.8에서 검토한다.
- Ambient 행동의 시드가 세션마다 달라서 같은 종류 펫들이 서로 다른 곳에 간다.

## 권리와 배포

- Claude 펫의 실루엣은 Anthropic Claude Code의 마스코트(Clawd)를 따른다.
- Codex 펫은 OpenAI 제품을 가리킨다.
- 개인 도구 안의 표지로 쓰는 것과 공개 배포는 다르다. 배포·패키징(Phase 7) 전에 두 회사의 상표·브랜드 지침을 확인해야 한다.
- 확인하지 못하면 일반화한 대체 펫(주황 상자형, 파란 구름형)으로 바꾼다. 대체 실루엣은 Phase 2.8 제작 목록에 선택 항목으로 넣는다.
- REF-05(스티커 목록)는 실루엣 참고 전용이다. 스티커 이미지·디자인을 복사하지 않는다.
